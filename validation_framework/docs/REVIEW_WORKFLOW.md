# Review workflow

1. Confirm exact manufacturer identity and official canonical product URL.
2. Separate model family from specific orderable variant. Register immutable EGC ID.
3. Extract and cite each physical system fact independently; distinguish module and system data.
4. Record unknown facts explicitly; reviewers can promote `listed` to `documented` after source verification.
5. Create algorithm compatibility claims only at evidence-specific states; don't infer performance.
6. Confirm proposed Knowledge Graph links against S03 before finalizing predicate vocabulary.
7. Publish only non-sensitive evidence, then check that master list/card/CSV/JSON identifiers agree.
